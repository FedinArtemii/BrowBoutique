# Бутик Бровей

Сайт школы-студии в Челябинске. Первый экран следует утверждённому варианту I «Взгляд в профиль». Онлайн-запись ведёт в DIKIDI.

## Локальное превью на WordPress

На Windows откройте PowerShell в папке репозитория и выполните:

```powershell
./tools/setup-local.ps1
```

Нужен PHP 8.1+ с расширениями PDO SQLite, SQLite3, Mbstring, Fileinfo и GD. Скрипт устанавливает WordPress с SQLite в папку `.local` и запускает сервер на [127.0.0.1:8793](http://127.0.0.1:8793/). При первом запуске он сохраняет данные для входа в `.local/admin.txt` и выводит ссылку на редактор главной страницы.

Тексты, фото, кнопки и список услуг редактируются в блоках главной страницы. Для другой установки WordPress загрузите тему из `theme/brow-boutique`, добавьте в новую страницу паттерн «Главная страница студии» и назначьте её главной. Навигацию можно заменить через меню WordPress.

## Клиентское демо

[Публичное демо на GitHub Pages](https://fedinartemii.github.io/BrowBoutique/) публикуется из ветки `gh-pages`. Это статический снимок страницы WordPress с действующей записью в DIKIDI. После правок в WordPress подготовьте новый снимок:

```powershell
node tools/export-demo.mjs
```

Скрипт сохраняет сайт в `.local/pages`. Перенесите экспорт в ветку `gh-pages` и отправьте изменения на GitHub.
